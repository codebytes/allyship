# Starting an Allyship Journey​

This repository contains the slide deck, demos, and resources for the "Starting an Allyship Journey​" talk. The talk provides an in-depth look at various aspects of allyship, privilege, unconscious bias, covering, and the importance of self-awareness and action in these areas.

- **What is Allyship?**
- **What is Privilege?**
- **What is Unconscious Bias?**
- **What is Covering?**
- **Why Me?**
- **How do I get started?**

## Slides

## Resources

The repository includes a variety of resources to demonstrate the concepts of allyship, privilege, unconscious bias, and more. These resources can help you understand these topics deeply and inspire you to take action.
